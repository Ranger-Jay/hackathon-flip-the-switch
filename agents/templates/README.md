# Private installation templates
These files are blank structures or synthetic examples, not deployed state. Copy to a new private directory using the helper's init-private command; it refuses an existing destination. Fill source/authority references from actual evidence, keep secrets outside these records, and review before use.

The example wake is intentionally historical/expired and uses a zero SHA. It is a schema illustration, not an actionable event. make-wake generates a current dry-run envelope; its handle is an explicit placeholder pending an independently verified runtime mapping. Never send that placeholder to Switch.

The workflow dry run validates structure only and is not installed or active. For a real installation, package_sha identifies the approved public package revision; a private workflow checkout SHA is a different value. Set the template's PACKAGE_SHA to that approved public revision when those differ. Run the helper against the matching package snapshot and retain both SHAs in the acceptance report.

Null fields mean unknown. Runtime sampling support unknown requires applied_temperature null. Complete provenance before promotion from scratch to durable fact. Actual authorization and transport identity are checked by the installation, not by a JSON file.
