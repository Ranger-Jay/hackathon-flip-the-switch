# Package provenance and scope
Prepared 2026-11-04 for the Council Room repository.

Persona profiles are PUBLIC-SAFE ADAPTATIONS of previously supplied Council descriptions and instructions. They preserve role, voice and aliases while adding the requested Switch runtime distinction and reusable operating rules. They are not verbatim replacements for the source profiles; private installation stewards retain the originals. Hostnames, private operational notes and credentials are excluded.

The numerical temperature targets are newly proposed package defaults. Earlier source profiles did not supply authoritative numeric values. No live runtime settings, agent names, avatars, access policies or memory have been applied by publishing these files.
