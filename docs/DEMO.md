# Demo storyboard — show the real room doing real work

**Status as of November 7:** A real multi-agent Council meeting was conducted; the final hackathon demo video is being edited. This document preserves the filming plan and must not be interpreted as a claim that the public static Vercel page has a private live Core feed.

**Target:** A tight 2–3 minute demo for Track 01. Screen-record the actual room, not a simulation presented as a live integration.

| Scene | Proof on screen | Suggested duration |
| :-- | :-- | --: |
| **The problem** | One concise sentence: disconnected assistants lose decision provenance | 10–15 s |
| **The room** | Real Switch room ID and distinct participant identities | 15–25 s |
| **The proposal** | Jay posts one non-sensitive business proposal | 15–20 s |
| **The collaboration** | Real addressed agent replies with different trade-offs | 35–50 s |
| **The judgment** | Reconciliation, unresolved UNKNOWNs and Jay's explicit decision | 25–35 s |
| **The record** | Reopen the persistent decision with citations | 20–30 s |
| **The value** | Show Switch is central; link to exact reproducible README steps | 15–25 s |

## Visual direction

A restrained cinematic opening: dark graphite canvas, luminous blue/teal/violet accents, clear portraits and a visual **Council Constellation** in 3D if the accessible implementation is actually ready. Prioritize live readability; never let animations cover proof, source IDs or the human decision.

## Production rules

- Redact credentials, private URLs/keys, customer data, personal records and internal-only issue context.
- Use recorded footage of the actual integration. Narration may be edited, but do not fake session participation or test outcomes.
- Visible status/identity must match real provider state.
- Include a quick highlight of the exact room message/decision record.
- Video URL and screenshots appear in README **only after verified publication**.
- If the 3D view is unreliable, record the strong 2D experience instead.

## Final judge-readiness gate

Public repository presentable; setup reproducible; real workflow runs; proof captured; independent review complete; version tags immutable; no secret leaks; limitations honest; Jay approves final submission.
